# Battery PCB

The battery board for one 18650 cell, designed in Altium Designer.

| File | What it is |
|---|---|
| `battery-pcb-v1.2-gerbers.zip` | Gerber and drill files, version 1.2 (2025-12-31), ready to upload to a PCB maker |
| `battery-pcb/battery-pcb.PrjPcb` | The Altium project; open this |
| `battery-pcb/battery-pcb.SchDoc` | Schematic |
| `battery-pcb/battery-pcb.PcbDoc` | Board layout |
| `battery-pcb/battery-pcb.pdf` | Board printout |
| `battery-pcb/fabrication-outputs/` | The same Gerber and drill files, unzipped, with Altium's reports |

`battery-pcb.PcbDoc` was saved on 2026-01-03, after the version 1.2 Gerbers. Regenerate the outputs from `battery-pcb.OutJob` if the board must match the latest layout.
